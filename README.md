# 中國文物博物館

這是一個以地圖、朝代與博物館為入口，整理中國重要文物的靜態網站 side project。網站收錄全國各地的收藏機構，並整合三個文物專題：「禁止出境展覽文物」、各省級博物館的「鎮館之寶」，以及各地博物館的「館藏精選」。每件文物都可以打開詳情卡，查看介紹、圖片、參考資料與影片。

- 原始碼：<https://github.com/wonderful-journey/china_museum>
- 純 HTML／CSS／JavaScript，沒有建置步驟，也沒有後端

## 收錄內容

| 項目 | 數量 | 說明 |
| --- | --- | --- |
| 收藏機構 | 643 家 | 國家一、二級博物館，以及收藏重要文物的考古機構、圖書館、高校；每館附簡介、城市與座標 |
| 禁止出境展覽文物 | 195 件／組 | 國家文物局 2002、2012、2013 年公布的三批名單 |
| 鎮館之寶 | 92 件 | 31 家省級博物館，每館至多三件 |
| 館藏精選 | 782 件 | 381 家博物館，每館至多三件 |
| 文物詳細介紹 | 265 件 | 改寫自百度百科、維基百科等資料，並附參考連結 |
| 影片 | 164 件文物、302 支 | 只收官方媒體或博物館頻道，且已確認可播放、台灣可觀看 |
| 文物圖片 | 281 件 | 維基共享資源（標示作者與授權），查無者改用百度百科詞條圖片 |

## 頁面

| 頁面 | 內容 |
| --- | --- |
| `index.html` 首頁 | 各專題入口、統計數字與網站說明 |
| `museums.html` 博物館名錄 | 用中國地圖與省份篩選所有收藏機構，可依等級、類型搜尋 |
| `museum.html?id=…` 收藏機構 | 單一博物館的簡介，以及百度百科、Google 地圖、百度地圖連結；列出該館在各專題中的文物 |
| `treasures.html` 鎮館之寶與館藏精選 | 依省份與博物館分組；可用「鎮館之寶／館藏精選」、類別、省份與關鍵字篩選（支援 `?kind=tr\|cl`、`?prov=省名`） |
| `forbidden.html` 禁止出境展覽文物 | 依批次、類別與地圖瀏覽三批禁止出境文物 |
| `dynasty.html` 依朝代瀏覽 | 把所有專題的文物依朝代排成時間軸，可跳到指定朝代 |

文物詳情卡（modal）在各頁通用，會顯示年代、類別、收藏單位、詳細介紹、圖片、參考資料、影片，以及維基百科與百度百科的連結。各頁右下角也有「返回頂端」按鈕。

## 專案結構

```
├── *.html                 6 個頁面
├── assets/
│   ├── css/base.css       全站樣式（含深色模式，色彩以 CSS 變數定義）
│   ├── js/
│   │   ├── common.js      導覽列、返回頂端、文物詳情卡、共用工具
│   │   ├── topics.js      把 forbidden / treasures / collections 整理成統一的 TOPICS 結構
│   │   ├── map.js         共用的 ECharts 中國地圖（省份分級上色、機構圓點）
│   │   └── home.js、museums.js、museum.js、treasures.js、forbidden.js、dynasty.js（各頁腳本）
│   ├── vendor/            echarts.min.js、china-geo.js（本地化，不依賴 CDN）
│   └── img/bg.jpg
└── data/
    ├── museums.js         MUSEUMS：收藏機構
    ├── forbidden.js       FORBIDDEN：禁止出境展覽文物
    ├── treasures.js       TREASURES：鎮館之寶
    ├── collections.js     COLLECTIONS：館藏精選
    ├── periods.js         PERIODS：朝代分期與年代比對規則
    ├── details.js         DETAILS：文物詳細介紹、參考資料、影片
    ├── images.js          IMAGES：文物圖片
    └── names_sc.js        NAMES_SC：文物名稱的簡體寫法（供百度百科搜尋）
```

資料檔都以全域常數的形式載入，每個檔案開頭的註解說明欄位格式。例如：

```js
// treasures.js / collections.js
[收藏機構 id, 類別, 名稱, 年代, 介紹]

// details.js（以文物名稱為鍵，各專題共用）
"文物名稱": { text: [段落…], refs: [[標題, 網址]…], videos: [[標題, 平台, 上傳者, 分鐘, 網址, 說明]…] }
```

## 本機執行

不需要安裝任何套件，用任何靜態伺服器開啟專案根目錄即可：

```bash
python -m http.server 8000
# 開啟 http://localhost:8000/
```

## 維護方式

- **新增文物**：在 `treasures.js`、`collections.js` 或 `forbidden.js` 加一筆資料；需要詳情時，在 `details.js`、`images.js` 以相同名稱補上。若名稱的繁簡寫法不同，也請在 `names_sc.js` 補上簡體寫法。
- **朝代歸類**：文物的「年代」欄位開頭會比對 `periods.js` 的規則；出現新的年代寫法時，要調整對應的 `re`。
- **快取版本**：所有 HTML 引用的 CSS／JS 都帶有 `?v=日期` 參數。修改後請一併更新版本號，避免瀏覽器讀到舊檔。
- **效能**：鎮館之寶頁以 IntersectionObserver 分批渲染（每批 24 張卡片）；朝代頁與名錄使用 `content-visibility: auto`。新增大量資料時不需額外處理。

## 資料來源與原則

- 博物館名單依國家文物局公布的一至五批國家一、二級博物館名單，只收錄以古代文物為主的機構；簡介參考百度百科與維基百科。
- 禁止出境展覽文物依國家文物局公布的三批名錄。
- 鎮館之寶以各省級博物館公布的名單與媒體報導為準。館藏精選取自百度百科各館詞條中明確點名的藏品，原件藏於他館者不收。
- 圖片要先確認與該館的文物是同一件才收錄。維基共享資源的圖片保留作者與授權資訊。
- 影片只收中央電視台、中華國寶、各地官方電視台與官方媒體等頻道，並逐一確認可以播放、在台灣可以觀看，且內容與該館文物相符。
- 文字介紹由多方資料整理改寫，不直接轉載；有爭議的年代或作者會在內文註明。

本網站為個人學習用的非商業 side project。文物圖片與影片的著作權屬原作者及各機構所有。
